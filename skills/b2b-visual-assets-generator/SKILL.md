# B2B Visual Assets Generator

Use this skill to generate consistent, conversion-focused visual assets for B2B websites and campaigns.

## When to use

Use for:

- Homepage hero visuals.
- Product diagrams and workflow illustrations.
- Blog and resource graphics.
- LinkedIn carousel/image concepts.
- OG/social preview cards.
- Case study and report graphics.
- Comparison tables, charts, and simple infographics.

## Inputs

- Asset type and placement.
- Target page and CTA.
- Buyer persona and funnel stage.
- Brand colors, logo rules, typography, and style references.
- Message to communicate.
- Required dimensions and file formats.

## Workflow

1. Identify the job of the asset: explain, persuade, reassure, compare, or capture attention.
2. Convert the message into one visual metaphor or diagram.
3. Choose format: hero, diagram, icon set, chart, card, cover, carousel.
4. Write a generation brief and, if needed, a prompt.
5. Produce variants for different channels.
6. Run visual QA and accessibility checks.
