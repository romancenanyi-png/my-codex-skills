# 小白外贸独立站：从建站到 SEO / GEO 运营

这是一套面向非程序员的实战教程。目标不是“生成一个好看的网页”，而是建立一个：

- 能被真实客户打开和使用；
- 能说明产品、能力、证据和采购条件；
- 能把询盘送到企业邮箱并留下来源；
- 能通过 GitHub 管理版本、通过 Vercel 发布；
- 能持续做 SEO、GEO 和询盘复盘的 B2B 网站。

## 这套教程从哪里来

内容从真实外贸建站项目中提炼，覆盖资料收集、页面架构、Codex 协作、Next.js 网站、GitHub、Vercel、域名、询盘表单、Google Search Console、SEO、GEO、关键词落页和上线后运营。

公开版只保留可复用的方法和验收规则，不包含客户名单、账号、企业邮箱、电话、询盘正文、令牌、密钥或内部报价。

## 最小可上线版本

第一次建站不要一上来做 100 个产品页。先完成：

1. 首页：一句话定位、核心产品、真实优势、证据、CTA。
2. 产品中心：产品类别和采购入口。
3. 一个重点产品或解决方案页。
4. About / Factory：公司、团队、流程和真实照片。
5. Contact / Request a Quote：能真实投递的询盘表单。
6. 一篇回答真实采购问题的指南。
7. Privacy 页面、robots、sitemap、canonical 和基础统计。

上线后再根据搜索数据、客户问题和询盘质量扩展，而不是为了数量批量生成薄页面。

## 必须记住的五句话

1. 真实资料比长提示词重要。
2. 网页能打开，不等于 Google 已收录。
3. Sitemap 是提示，不保证抓取或索引。
4. GEO 没有“保证 AI 引用”的神奇标签，本质仍是可访问、可信、直接回答问题的内容。
5. 表单显示成功、平台接收邮件、企业邮箱收到邮件，是三个不同的验收点。
