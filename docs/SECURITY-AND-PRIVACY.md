# 安全与隐私

## 永不提交

- 客户、潜客或员工的真实姓名、私人邮箱、电话、WhatsApp、地址和对话正文。
- 邮箱登录、Cookie、令牌、API 密钥、广告账户 ID、付款或预算凭证。
- 未公开报价、PI、合同、询盘、发送历史、退信详情和内部评分表。
- 未取得再分发许可的客户素材、第三方视频和带水印内容。

## 可公开的形式

- 用 `[COMPANY]`、`[CONTACT]`、`[COUNTRY]` 等占位符表达字段。
- 只记录“如何判断”，不记录“判断了谁”。
- 将事实、推断、缺失证据分开，所有结果保留来源 URL 和观察日期。
- 发送、发布、投放、上传和修改线上站点前，取得明确授权。

## 使用者责任

使用者需遵守目标平台条款、隐私与反垃圾邮件法律、素材许可及所在地区法规。本仓库提供运营工作流，不构成法律建议，也不会绕过登录、权限或平台限制。
